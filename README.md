# 🍎 Fruits and Vegetables Detection Dataset (YOLO Format)

## 📌 Overview
This project contains a custom dataset for **fruit and vegetables detection** using the **YOLO (You Only Look Once)** object detection model. The dataset includes labeled images of various fruits for training, validation, and testing purposes.

The goal of this dataset is to train a model capable of accurately detecting and classifying fruits in real-time applications. In this current version there are only 6 foods that the model can detect.

---

## 🧠 Supported Model
- YOLOv5 / YOLOv12 (compatible)
- PyTorch-based training using Google Colab

---

## 🍓 Classes
The dataset currently includes the following fruit classes:

- Apple
- Banana
- Orange
- Philippine Lime
- Onion
- Garlic
